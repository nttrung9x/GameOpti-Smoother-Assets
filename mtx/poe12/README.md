# 🇻🇳 Giới thiệu

Đây là **kho tài nguyên (Assets Repository)** chính thức của **GameOpti**, chứa toàn bộ hình ảnh được phần mềm sử dụng.

**GameOpti** là công cụ tối ưu dành riêng cho **Path of Exile 1** và **Path of Exile 2**, giúp cải thiện trải nghiệm chơi game bằng cách tối ưu hiệu ứng hình ảnh và hỗ trợ hiển thị tài nguyên một cách nhanh chóng.

### Tính năng của GameOpti

- 🚀 Giảm giật, lag trong các trận chiến
- ⚡ Cải thiện FPS trên máy cấu hình thấp và trung bình
- 🎨 Hiệu ứng hình ảnh rõ ràng hơn
- 🛡️ Dễ dàng áp dụng và khôi phục
- 🌐 Tự động cập nhật dữ liệu trực tuyến

---

## 📦 Hướng dẫn cài đặt Assets

1. Tải phiên bản **Assets** mới nhất tại mục **Releases**.
2. Giải nén file ZIP vào thư mục **`Icon`** của GameOpti.
3. Chọn **Replace All** nếu được hỏi ghi đè tệp.

Sau khi giải nén, cấu trúc thư mục sẽ như sau:

```text
GameOpti
└── Icon
    └── mtx
        └── poe12
            └── Misc
                └── IridescentMonarchWings.png
```

Ví dụ đường dẫn đầy đủ:

```text
GameOpti\Icon\mtx\poe12\Misc\IridescentMonarchWings.png
```

> ⚠️ **Lưu ý:** Thư mục **Icon** phải nằm trong thư mục gốc của GameOpti. Nếu đặt sai vị trí, phần mềm sẽ không thể tải hình ảnh.

# 🇺🇸 About

This repository contains the **official image assets** used by **GameOpti**.

**GameOpti** is an optimization tool designed specifically for **Path of Exile 1** and **Path of Exile 2**, helping improve gameplay by optimizing visual effects and providing fast access to in-game assets.

### GameOpti Features

- 🚀 Reduce lag during intense combat
- ⚡ Improve FPS on low and mid-range PCs
- 🎨 Cleaner visual effects for better visibility
- 🛡️ Easy Apply / Restore
- 🌐 Automatic online updates

---

## 📦 Installing Assets

1. Download the latest **Assets** package from the **Releases** page.
2. Extract the ZIP file into the **`Icon`** folder of your GameOpti installation.
3. Replace existing files if prompted.

After extraction, your folder structure should look like:

```text
GameOpti
└── Icon
    └── mtx
        └── poe12
            └── Misc
                └── IridescentMonarchWings.png
```

Example full path:

```text
GameOpti\Icon\mtx\poe12\Misc\IridescentMonarchWings.png
```

> ⚠️ **Important:** The **Icon** folder must be placed in the root directory of GameOpti. Otherwise, GameOpti will not be able to load the images correctly.
